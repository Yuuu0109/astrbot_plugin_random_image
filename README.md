# 关键词随机图库 (astrbot_plugin_random_image)

在私聊或群聊中发送某个关键词,机器人从对应分类中随机抽取一张图片或 GIF 发送。图库直接在对话中用中文语句管理,无需指令前缀。

## 使用方法

| 发送内容 | 作用 |
|---|---|
| `分类名` 或 `别名` | 随机发送该分类下的一张图片/GIF |
| `添加 分类名 [别名...]` + 附带图片 | 添加图片(可多张,分类不存在则自动创建,可同时绑定别名) |
| `添加 分类名`(引用一条含图消息) | 把被引用消息中的图片添加到分类 |
| `别名 分类名 别名1 别名2` | 为已有分类绑定新的触发词 |
| `列表` | 查看所有分类(含别名与数量) |
| `列表 分类名` | 查看该分类的图片序号 |
| `删除 分类名 序号` | 删除该分类下第 N 张图片 |
| `删除分类 分类名` | 删除整个分类及其全部图片 |
| `图库帮助` | 查看帮助 |

示例:

- 群聊发送 `a` → 机器人从分类 `a` 随机发一张图
- 发送 `添加 a 啊 A` 并附带 3 张图 → 图片存入分类 `a`,同时绑定别名 `啊`、`A`
- 引用别人的图片消息,发送 `添加 猫猫` → 被引用的图片存入分类 `猫猫`

## 说明

- **图库按会话隔离**:每个群聊/私聊拥有独立的分类、别名和图片,互不可见。群 A 添加的图片,群 B 无法触发。
- 所有人均可添加/删除(无权限控制)。
- 图片按内容 sha256 命名存储,**同一分类内自动去重**;重复添加会提示跳过张数。
- 支持格式:jpg / jpeg / png / gif / webp / bmp。
- 关键词触发要求整条消息(去首尾空格后)与分类名/别名完全一致。
- 引用添加:aiocqhttp(QQ/NapCat 等)与 Telegram 平台会自动解析被引用消息;其他平台若不支持会给出无图提示。
- 分类名/别名不能包含空格和 `/ \ : * ? " < > |` 等字符,且不能使用保留指令词。

## 数据存储

```
data/plugin_data/astrbot_plugin_random_image/
├── categories.json              # {会话: {分类名: [别名...]}}
└── images/
    └── <会话标识>/              # 由平台名:消息类型:会话ID 净化而来
        └── <分类名>/
            └── <sha256>.jpg/.png/.gif/...
```
